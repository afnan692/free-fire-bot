# FreeFire Level Up Bot - Railway Deployment

## 🚀 এক Click এ Deploy করুন!

### আপনার করণীয় (মাত্র ৩টি ধাপ):

#### Step 1: GitHub Repository তৈরি করুন (২ মিনিট)
1. এই link এ যান: https://github.com/new
2. Repository name: `toxic-bot`
3. Private select করুন
4. Create repository click করুন

#### Step 2: ফাইলগুলো GitHub এ upload করুন (১ মিনিট)
GitHub repository এ যান → "uploading an existing file" → সব ফাইল drag & drop করুন → Commit changes

#### Step 3: Railway এ Deploy করুন (১ মিনিট)
1. এই link এ যান: https://railway.app/new
2. "Deploy from GitHub repo" click করুন
3. আপনার `toxic-bot` repository select করুন
4. Deploy click করুন
